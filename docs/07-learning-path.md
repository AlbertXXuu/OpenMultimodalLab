# 学习路线

学习内容必须服务于当前里程碑，不采用“全部学完再开始”的方式。

## 阶段一：Python 工程基础

需要掌握：

- 包结构和 `pyproject.toml`；
- `dataclass`、类型标注和 Protocol；
- JSONL 流式读写；
- `argparse` 与退出码；
- `unittest`、临时目录和异常测试；
- Git 分支、提交和 Release。

产物：离线评测闭环和自动测试。

## 阶段二：计算机视觉与多模态模型

需要掌握：

- 图像尺寸、颜色空间和预处理；
- Vision Encoder、Projector、LLM 的基本结构；
- prompt 模板和 chat template；
- token、上下文长度和生成参数；
- 不同模型对图片分辨率的处理差异。

产物：第一个真实 VLM Adapter。

## 阶段三：评测方法

需要掌握：

- exact match、关键词、F1 和结构化评分；
- 主观评分与模型裁判的偏差；
- 数据泄漏、难度分层和样本覆盖；
- 重复实验、p50/p95 和置信区间基础；
- 公平比较与失败分析。

产物：两个模型的可复现对比报告。

## 阶段四：推理系统

需要掌握：

- CPU/GPU、显存和数据传输；
- dtype、量化和 KV Cache；
- 模型加载、prefill、decode；
- warm-up、同步和精确计时；
- batching、缓存和吞吐/延迟权衡。

产物：性能指标与低显存实验。

## 阶段五：开源工程

需要掌握：

- CI、版本与变更日志；
- Issue/PR 工作流；
- Apache-2.0、模型许可证和数据许可证基础；
- 可复现教程和技术写作；
- 如何接受反馈并保持兼容。

产物：可公开使用的 `v1.0`。

## 阅读方法

每次只记录四项：

1. 这篇资料解决什么问题？
2. 哪个设计能直接用于项目？
3. 哪个假设需要实验验证？
4. 本周会产生什么代码或文档变化？

如果无法回答第 4 项，暂时不把它列为本周必读。
