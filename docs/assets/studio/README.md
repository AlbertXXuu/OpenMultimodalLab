# Studio viewport evidence

These full-page screenshots and [`viewport-audit.json`](viewport-audit.json) record the bounded
OpenMultimodalLab Studio closure check for software `1.1.0-candidate` on 2026-08-30. They are UI
validation artifacts, not benchmark evidence and not a change to the immutable v1.0 research
record.

The audit covers 900, 1024, 1280, 1440, and 1600px browser widths, initial disclosure state,
horizontal overflow, responsive column behavior, critical target height, shared header computed
styles, and keyboard activation.
